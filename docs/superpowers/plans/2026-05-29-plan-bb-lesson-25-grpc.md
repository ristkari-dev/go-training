### Design decisions (2 user-approved + plan-recommended)

**User-approved via brainstorming:**

1. **Keep the HTTP face + add gRPC.** Carry `logparse` + `logstats` + `cmd/logstats-server` (HTTP) verbatim; add the gRPC surface. Both faces share the same `logstats.Store` — "transport is a face over domain logic."
2. **Five slide concepts:** protobuf IDL + types · codegen workflow · unary RPC · client-streaming RPC · interceptors + gRPC-vs-REST.

**Plan-recommended:**

3. **Pin grpc v1.73.0** (not the latest v1.81). v1.76+ declares `go 1.24` and v1.81 declares `go 1.25`; **v1.73.0 is the newest grpc that declares `go 1.23`**, so adding it keeps the course module's `go 1.23` directive intact (verified: a clean tidy with v1.73.0 leaves `go 1.23`, 4 small indirect deps, go.sum ~34 lines). protobuf v1.36.11 is compatible and doesn't push the directive.
4. **Generated code committed per-tree**, generated by a `make proto` target. Build/CI/students need no `protoc`. `go_package` differs per tree (exercises vs solutions import paths), so each tree has its own `.proto` + generated package.
5. **bufconn for tests** (`grpc.NewClient` + `passthrough:///bufnet` + `WithContextDialer` + insecure creds — the modern, non-deprecated API). No real ports.
6. **Warm-up is a standalone unary `greeter`** (its own tiny proto + generated code + `Greet` impl), mirroring how prior warm-ups were small and self-contained. The main exercise is the streaming `logstats` service.
7. **`.golangci.yml` excludes generated `*.pb.go`** from lint.

### Verified facts (prototyped before writing this plan)

- The full stack — `proto` → `protoc` codegen → service (unary `GetStats` + client-streaming `Ingest`) → unary+stream logging interceptors → `bufconn` client tests — **builds and passes `-race`**.
- `protoc --go_out=. --go_opt=module=<modpath> --go-grpc_out=. --go-grpc_opt=module=<modpath> <proto>` (run from repo root) routes generated files to the dir implied by `go_package` minus the module prefix.
- Deps: grpc v1.73.0 + protobuf v1.36.11 → module stays **go 1.23**, indirect = `golang.org/x/net v0.38.0`, `x/sys v0.31.0`, `x/text v0.23.0`, `google.golang.org/genproto/googleapis/rpc`. go.sum ~34 lines.
- Generated `*.pb.go` use the modern generics stream API: `pb.LogStats_IngestServer` = `grpc.ClientStreamingServer[LogLine, IngestSummary]`, with `Recv()`/`SendAndClose()`.
- Hand-written code is gofmt-clean (gofmt aligns the `store` field under the embedded `pb.UnimplementedLogStatsServer`) and vet-clean.

// Package grpcsrv implements the LogStats gRPC service over the shared
// logstats.Store — the same accumulator the HTTP face uses. Reference impl.
package grpcsrv

import (
	"context"
	"io"
	"log/slog"

	"google.golang.org/grpc"

	"github.com/ristkari-dev/go-training/lessons/25-grpc/solutions/internal/logparse"
	"github.com/ristkari-dev/go-training/lessons/25-grpc/solutions/internal/logstats"
	pb "github.com/ristkari-dev/go-training/lessons/25-grpc/solutions/proto/logstatspb"
)

type Server struct {
	pb.UnimplementedLogStatsServer
	store *logstats.Store
}

func New(store *logstats.Store) *Server { return &Server{store: store} }

func (s *Server) GetStats(ctx context.Context, _ *pb.StatsRequest) (*pb.StatsReply, error) {
	counts, total := s.store.Snapshot()
	out := make(map[string]int32, len(counts))
	for k, v := range counts {
		out[k] = int32(v)
	}
	return &pb.StatsReply{Counts: out, Total: int32(total)}, nil
}

func (s *Server) Ingest(stream pb.LogStats_IngestServer) error {
	delta := map[string]int{}
	var accepted, parsed, failed int32
	for {
		line, err := stream.Recv()
		if err == io.EOF {
			s.store.Merge(delta)
			return stream.SendAndClose(&pb.IngestSummary{
				Accepted: accepted, Parsed: parsed, Failed: failed,
			})
		}
		if err != nil {
			return err
		}
		accepted++
		if e, perr := logparse.ParseLine(line.GetLine()); perr == nil {
			delta[e.Level]++
			parsed++
		} else {
			failed++
		}
	}
}

// LoggingUnaryInterceptor logs each unary call (gRPC's middleware).
func LoggingUnaryInterceptor(logger *slog.Logger) grpc.UnaryServerInterceptor {
	return func(ctx context.Context, req any, info *grpc.UnaryServerInfo, handler grpc.UnaryHandler) (any, error) {
		resp, err := handler(ctx, req)
		logger.Info("unary", "method", info.FullMethod, "err", err)
		return resp, err
	}
}

// LoggingStreamInterceptor logs each streaming call.
func LoggingStreamInterceptor(logger *slog.Logger) grpc.StreamServerInterceptor {
	return func(srv any, ss grpc.ServerStream, info *grpc.StreamServerInfo, handler grpc.StreamHandler) error {
		err := handler(srv, ss)
		logger.Info("stream", "method", info.FullMethod, "err", err)
		return err
	}
}

// grpcsrv service (with logging interceptors) over a TCP listener,
// sharing a logstats.Store. Graceful stop on SIGINT.

// Usage: logstats-grpc-server 127.0.0.1:9090
package main

import (
	"context"
	"log/slog"
	"net"
	"os"
	"os/signal"

	"google.golang.org/grpc"

	"github.com/ristkari-dev/go-training/lessons/25-grpc/solutions/internal/grpcsrv"

	ctx, stop := signal.NotifyContext(context.Background(), os.Interrupt)
	defer stop()

	addr := "127.0.0.1:9090"
	if len(os.Args) > 1 {
		addr = os.Args[1]
	}
	if err := run(ctx, addr); err != nil {
		slog.Error("grpc server failed", "err", err)
		os.Exit(1)
	}
}

func run(ctx context.Context, addr string) error {
	logger := slog.New(slog.NewJSONHandler(os.Stdout, nil))
	lis, err := net.Listen("tcp", addr)
	if err != nil {
		return err
	}
	srv := grpc.NewServer(
		grpc.UnaryInterceptor(grpcsrv.LoggingUnaryInterceptor(logger)),
		grpc.StreamInterceptor(grpcsrv.LoggingStreamInterceptor(logger)),
	)

	go func() {
		<-ctx.Done()
		srv.GracefulStop()
	}()

	logger.Info("grpc listening", "addr", lis.Addr().String())
	return srv.Serve(lis)
}

// Package main is the lesson 25 LogStats gRPC client. It streams stdin
// lines to the server via the Ingest client-streaming RPC, prints the
// summary, then calls the unary GetStats.
//
// Usage: logstats-grpc-client -addr=127.0.0.1:9090 < app.log
package main

import (
	"bufio"
	"context"
	"flag"
	"fmt"
	"io"
	"os"
	"os/signal"

	"google.golang.org/grpc"
	"google.golang.org/grpc/credentials/insecure"

	pb "github.com/ristkari-dev/go-training/lessons/25-grpc/solutions/proto/logstatspb"
)

func main() {
	ctx, stop := signal.NotifyContext(context.Background(), os.Interrupt)
	defer stop()

	addr := flag.String("addr", "127.0.0.1:9090", "gRPC server address")
	flag.Parse()

	if err := run(ctx, *addr, os.Stdin, os.Stdout); err != nil {
		fmt.Fprintln(os.Stderr, "error:", err)
		os.Exit(1)
	}
}

func run(ctx context.Context, addr string, stdin io.Reader, stdout io.Writer) error {
	conn, err := grpc.NewClient(addr, grpc.WithTransportCredentials(insecure.NewCredentials()))
	if err != nil {
		return err
	}
	defer conn.Close()
	client := pb.NewLogStatsClient(conn)

	// Stream stdin lines via the client-streaming Ingest RPC.
	stream, err := client.Ingest(ctx)
	if err != nil {
		return err
	}
	sc := bufio.NewScanner(stdin)
	for sc.Scan() {
		if err := stream.Send(&pb.LogLine{Line: sc.Text()}); err != nil {
			return err
		}
	}
	if err := sc.Err(); err != nil {
		return err
	}
	summary, err := stream.CloseAndRecv()
	if err != nil {
		return err
	}
	fmt.Fprintf(stdout, "ingested: accepted=%d parsed=%d failed=%d\n",
		summary.GetAccepted(), summary.GetParsed(), summary.GetFailed())

	// Then the unary GetStats.
	reply, err := client.GetStats(ctx, &pb.StatsRequest{})
	if err != nil {
		return err
	}
	fmt.Fprintf(stdout, "stats: total=%d counts=%v\n", reply.GetTotal(), reply.GetCounts())
	return nil
}

## Task 5: Slide deck — 5 concepts (controller inline)

Heavy-explanatory per concept. **File:** `lessons/25-grpc/slides/slides.md`.

1. **Protobuf IDL + type system** — `message`/`service`/`rpc`, scalars/`map`/`repeated`, field numbers + wire compatibility, proto3 semantics. *Common mistake:* changing/reusing a field's number (breaks wire compat with deployed peers).
2. **Codegen workflow** — `protoc` + `protoc-gen-go`/`protoc-gen-go-grpc`, `option go_package`, the `module=` opt, committed `*.pb.go`, `make proto`; build needs no protoc. *Common mistake:* hand-editing generated files (lost on regen) / committing nothing and breaking others' builds.
3. **Unary RPC** — `GetStats`: server method signature, the `UnimplementedLogStatsServer` embed (forward compat), client call with ctx + a `status` error. *Common mistake:* not embedding `Unimplemented…` → adding an RPC breaks every existing server at compile time.
4. **Client-streaming RPC** — `Ingest`: server `Recv()` loop to `io.EOF` then `SendAndClose`; client `Send()` loop then `CloseAndRecv`; the four streaming modes (unary, server-, client-, bidi). *Common mistake:* not terminating the stream (forgetting `CloseAndRecv`/the `io.EOF` check) → hang.
5. **Interceptors + gRPC vs REST** — unary/stream interceptors = gRPC middleware (logging, auth, metrics); gRPC vs REST tradeoffs (typed contract + codegen + streaming + HTTP/2 vs human-debuggable + ubiquitous + cacheable). *Common mistake:* cross-cutting logic copy-pasted into every method instead of an interceptor; reaching for gRPC for a browser-facing public API.
